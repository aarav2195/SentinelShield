# SentinelShield

## Project Overview

SentinelShield is a lightweight Web Application Firewall (WAF) and Intrusion Detection System (IDS) developed using Python and Flask. The system inspects every incoming HTTP request before it reaches the application, detects common web-based attacks, logs suspicious activities, enforces rate limiting, and provides a real-time security dashboard for monitoring and analysis.

The project demonstrates practical web security concepts including request inspection, rule-based attack detection, security logging, dashboard analytics, and malicious request blocking.

---

## Key Features

- HTTP Request Inspection
- SQL Injection Detection
- Cross-Site Scripting (XSS) Detection
- Command Injection Detection
- Directory Traversal Detection
- Local File Inclusion (LFI) Detection
- Rate Limiting
- Request Logging
- Real-time Security Dashboard
- Attack Analytics
- Threat Level Monitoring

## Output

The application analyzes every incoming HTTP request and classifies it as either:

- Safe Request
- Malicious Request

Detected attacks are blocked immediately, recorded inside request logs, and visualized through the dashboard.
